# Sabeeh TK — Python-Django Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For a local development server, open a terminal in this folder and run:
   `python -m http.server 8000`
4. Visit `http://localhost:8000`.

## Personalize before publishing
Search `index.html` for these placeholders and replace them:
- `your.email@example.com`
- `yourusername` (GitHub and LinkedIn links)
- Project One / Project Two / Project Three: replace sample descriptions with real projects, features, and repository URLs.
- Add your real phone/contact details if you want them public.

## Notes
- The projects are starter examples, not claims that you have completed these projects. Replace them with your actual work before sending this portfolio to recruiters.
- The Google Fonts import requires internet access; the site falls back to system sans-serif fonts.
- This is a static front-end portfolio. It does not require Django or a database to run.
